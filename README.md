# Work and Class Schedule Checker

By Nicholas Sanders

## Project Purpose
This Python application will help college students manage their work and school schedules by identifying conflicts between work shifts, classes, and assignment deadlines.

## Planned Features
- Enter work shifts and class meetings with start and end times.
- Flag work shifts that overlap with classes.
- Highlight assignment deadlines that fall during work shifts.
- Display schedule entries in order.
- Calculate total work hours for the week.

## Planned Tools
Python and Tkinter will be used to create the application and its interface.
